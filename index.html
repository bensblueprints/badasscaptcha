Compatible by design

Drop it into your existing workflow.

Create with POST /in.php and retrieve with GET /res.php. Responses use the familiar plain-text 2Captcha-compatible contract.

REQUEST / 01

Create a reCAPTCHA v2 task

curl -X POST 'https://badasscaptcha.com/in.php' \
  --data-urlencode 'key=YOUR_API_KEY' \
  --data-urlencode 'method=userrecaptcha' \
  --data-urlencode 'googlekey=YOUR_SITE_KEY' \
  --data-urlencode 'pageurl=https://example.com/register'

REQUEST / 02

Poll for the result

curl --get 'https://badasscaptcha.com/res.php' \
  --data-urlencode 'key=YOUR_API_KEY' \
  --data-urlencode 'action=get' \
  --data-urlencode 'id=TASK_ID'

Integration details

CAPTCHA API FAQ

Which CAPTCHA types are supported?

The current API supports reCAPTCHA v2 through userrecaptcha and image CAPTCHA through base64.

Is this compatible with 2Captcha clients?

The service exposes compatible /in.php and /res.php endpoints and plain-text responses for the supported methods.

What happens to failed tasks?

Failed and timed-out tasks follow an automatic refund path. Public task mappings last five minutes.
